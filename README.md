# ⚡ Hermes Messenger Portal

Hermes es un portal de mensajería instantánea ultra-rápida. Su interfaz interactiva permite enviar mensajes, simular la latencia y la entrega divina, y ver métricas en tiempo real.

## 🚀 Despliegue en Railway

Este repositorio está preparado para ser desplegado en [Railway](https://railway.app). Detecta automáticamente el archivo `package.json` para levantar el servidor Express en el puerto proveído.

## 🛠️ Instalación y ejecución local

1. Instala las dependencias:
   ```bash
   npm install
   ```
2. Ejecuta el servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Abre tu navegador en `http://localhost:3000`.
